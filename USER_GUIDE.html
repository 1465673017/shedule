A大橙子课时统计使用教程

Windows 与 macOS 通用：从首次配置、学生管理和排课，到点名、统计、工资与数据导出的完整操作说明。

除特别标注的系统差异外，两套系统的界面、按钮名称和操作流程一致。页面截图来自 macOS。

版本选择与首次启动

启动后先打开“快速开始”，了解基础设置、教师类型、阶段、时间、学生和排课的推荐顺序。

Windows

Windows 提供以下两个版本：

版本使用方式
A大橙子课时统计1.2.2（正式版）单文件版无需解压应用目录，双击单文件程序即可运行。
A大橙子课时统计1.2.2（正式版）绿色版完整解压后，在解压得到的文件夹中双击应用程序运行。

若系统出现安全提示，请先核对文件来源，再选择“更多信息”并允许运行。

macOS

macOS 提供以下两个版本：

版本使用方式
A大橙子课时统计（正式版-1.2.2）-x64打开正式版安装包，按系统提示完成安装后运行。
macos-green-zip完整解压 ZIP 后，在解压得到的文件夹中运行应用。

若系统阻止打开，请在“系统设置 → 隐私与安全性”中确认允许；只运行来源可信的应用。

认识主界面

  1. 操作区：导出数据、重置课表、快速开始、基础设置和批量导入学生。
  2. 科目池/学生池：管理并拖拽科目或学生。
  3. 周次导航：左右箭头切换周次，“今天”返回本周。
  4. 课表：横向为星期、纵向为课时；点击或拖入内容完成排课。
  5. 日期范围：点击顶部周日期可打开统计。

首次基础配置

3.1 基础设置与主题

  1. 点击左侧“基础设置”。
  2. 按需开启历史课表保护，避免误改过去课程。
  3. 选择教师类型；没有学科背景的课程会归到该科目。
  4. 选择默认、暗色或浅绿色主题并保存。

3.2 年级设置

  1. 切换“年级设置”。
  2. 点击“添加年级”，填写名称并选择颜色。
  3. 保存后可编辑、拖拽排序或随机配色。

3.3 阶段设置

  1. 需要按学期、季度或寒暑期独立排课时，开启分段排课。
  2. 填写阶段名称、起止日期；可增加至 12 个阶段。
  3. 保证日期不重叠，然后保存。

3.4 时间设置

  1. 设置每日节数、首节开始时间、单节和课间时长。
  2. 按需插入午休或晚间休息。
  3. 点击“应用快速设置”，再在高级设置中逐节微调并保存。

科目管理

  1. 切换到“科目池”，点击“添加科目”。
  2. 填写名称，可选填老师姓名。
  3. 选择预设颜色或输入 HEX 自定义颜色。
  4. 点击保存。以后可通过卡片编辑图标修改或删除。
删除已用于排课的科目前，建议先导出数据或调整相关课程。

学生管理

5.1 添加单个学生

  1. 切换“学生池”，点击“添加学生”。
  2. 输入姓名并选择年级。
  3. 设置普通、1v1 或试听类型；1v1 与试听不能同时启用。
  4. 保存。可按全部、进行中、已结课和试听筛选。

5.2 批量添加

  1. 点击“批量导入学生”。
  2. 粘贴名单，姓名可用顿号、逗号或换行分隔。
  3. 年级用 1–12 表示一年级至高三，例如 1张三、2李四、3王五；不写编号默认一年级。
  4. 点击“识别并导入”，检查结果。

排课与调整

  1. 先切换到目标周。
  2. 把科目卡片拖到目标日期和节次，或直接点击空白课位。
  3. 确认科目，搜索并勾选学生。
  4. 设置循环方式或生效范围并保存。
  5. 也可把学生卡片拖入已有课程。

手动课程

  1. 打开手动添加入口。
  2. 选择日期、时间、科目和学生。
  3. 填写实际上课时长并保存，课程将进入统计与课时表导出。
拖动整节课程可移动课位；拖动单个学生可调整所在课程；拖回左侧回收区域可移除。修改循环课程前请确认生效周次。

学生点名与出勤

  1. 找到已排课程并打开点名窗口。
  2. 逐个记录到课、请假或缺勤状态。
  3. 实际时长与计划不同时，填写实际上课时长。
  4. 保存记录。

出勤与实际时长会影响文字统计、图表统计、工资和课时表 Excel。

课程数据批量导入

  1. 打开“批量导入课程”。
  2. 粘贴符合应用格式的课程 JSON。
  3. 普通排课选择普通导入；已开启分段排课且数据带阶段标记时选择阶段导入。
  4. 执行导入并检查新增、跳过和异常项目。
  5. 回到对应周次核对课表。
导入前建议备份。阶段导入中的课程日期必须属于已配置阶段。

课时统计

9.1 图表统计

  1. 点击主界面顶部日期范围。
  2. 选择日、周、月或年统计。
  3. 用日期选择器切换范围。
  4. 切换课时、人数或课时费统计，查看总览、趋势和班型对比。

9.2 文字统计

  1. 打开文字统计。
  2. 选择周期，用上一项、下一项或日期控件切换。
  3. 查看课程数、课时、到课和分类明细。

课时费与工资

  1. 打开图表统计并切换“课时费统计”。
  2. 打开工资设置，填写月底薪并选择教师星级。
  3. 保存后重新查看所选月份。
折算课时 = 实际上课时长 × 班型系数 × 年级系数

系统每月先扣除固定 8 小时基本课时，再对剩余工资课时分段累进计价；星级加成叠加到各阶梯单价，不改变折算课时。具体系数和阶梯以应用内规则页为准。

工资依赖学生年级、班型、出勤和实际时长。修改这些数据后请重新打开统计。

导出数据

课时表 Excel

  1. 点击“导出数据”。
  2. 选择开始与结束日期。
  3. 点击“导出课时表 Excel”并选择保存位置。

内容包括课程、学生、出勤和实际上课时长。

当前课表图片或 Excel

  1. 先切换到目标周。
  2. 打开导出，选择“导出课表图片”或“导出课表 Excel”。
  3. 选择文件名和保存位置。

系统保存差异

  • Windows：保存窗口常见“桌面”“文档”“下载”；文件被占用时先关闭 Excel 中的同名文件。
  • macOS：对应位置为“桌面”“文稿”“下载”；先关闭 Numbers、Excel 或其他正在打开该文件的程序。
提示无权限时，改存到当前账户的“下载”或“文档/文稿”，不要直接保存到受保护的应用目录。

重置与备份

  • 按日期重置：依次选择起点和终点，仅清除范围内课程。
  • 重置课表：清空排课、循环和考勤，保留科目、学生、手动课程、年级、时间和设置。
  • 全部重置：清空课表、学生、手动课程、考勤和循环数据。

系统备份差异

  • Windows A大橙子课时统计1.2.2（正式版）单文件版：迁移或重装前，建议先使用应用内导出功能备份数据。
  • Windows A大橙子课时统计1.2.2（正式版）绿色版：完全退出应用后再备份，保留完整的解压文件夹，并优先使用应用内导出迁移数据。
  • macOS macos-green-zip：完全退出应用后再备份，保留完整的解压文件夹，并优先使用应用内导出迁移数据。
  • macOS A大橙子课时统计（正式版-1.2.2）-x64：迁移前建议优先使用应用内导出功能。
全部重置不可轻易恢复，执行前请先导出或备份。

操作提示与常见问题

应用在确认、取消或异常操作时会显示消息窗口。先阅读提示内容，再选择“确定”或“取消”。

课程拖不进去

检查目标是否被占用、学生是否冲突、试听学生是否已排课，以及历史保护是否禁止修改过去日期。

统计结果不正确

依次核对日期、学生、点名状态、实际时长、年级、班型和工资星级。

移动绿色压缩包版后数据消失

请保留 macos-green-zip 解压后的完整文件夹，并优先通过应用内导出迁移数据。

Windows 更换版本或电脑后数据未迁移

更换单文件版、绿色版或电脑前，建议先在原应用中导出数据。

macOS 阻止打开

在“系统设置 → 隐私与安全性”中允许打开来源可信的应用。
