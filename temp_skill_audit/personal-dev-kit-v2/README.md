# Personal Dev Kit v2

为个人开发者准备的 Python + Web + 数据处理开发工具箱。

## 三个模板

- `templates/personal-lite`：CLI、自动化脚本、小型 Python 工具
- `templates/personal-web`：FastAPI + React/Vite/TypeScript
- `templates/personal-data`：FastAPI + Jinja2/HTMX 风格的数据导入、处理、导出工具

## 推荐用法

1. 复制最接近需求的模板。
2. 将 `agents/fullstack.md` 或对应规则合并为项目根目录的 `AGENTS.md`。
3. 把需要的工作流文档交给 Codex 或 TRAE。
4. 先使用 `prompts/build-feature.md` 规划，再实现。
5. 修改后运行测试、Ruff 和类型检查。

这些文件是原创工作流模板，不包含第三方仓库代码。
